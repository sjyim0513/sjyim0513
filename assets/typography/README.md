# Stack typography

Typography: [KoPubWorld Dotum](https://www.kopus.org/biz-electronic-font2/) — Ministry of Culture, Sports and Tourism & Korea Publishers Society.

The supplied KoPubWorld Dotum Medium and Bold fonts were used to typeset the fixed labels. These SVGs contain finished letter outlines, not font files or embedded font software. Medium is used for category labels and badges; Bold is used for the Tech Stack heading.

The existing technology logos were retained from the [Shields.io](https://shields.io/docs/logos) badges. Light and dark heading variants support both GitHub themes. The README retains accessible image labels and its heading structure.
