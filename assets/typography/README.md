# Profile typography

Typography: [KoPubWorld Dotum](https://www.kopus.org/biz-electronic-font2/) — Ministry of Culture, Sports and Tourism & Korea Publishers Society.

The supplied KoPubWorld Dotum Medium and Bold fonts were used to typeset the fixed text. These SVGs contain finished letter outlines, not font files or embedded font software. Bold is used for the first introduction sentence, Tech Stack heading and category labels. Medium is used for the focus sentence and badges.

The first introduction sentence is split into two inline graphics so it can wrap on smaller screens without shrinking the whole sentence. Both parts use a shared baseline. Text is preserved in image labels for accessibility.

The existing technology logos were retained from the [Shields.io](https://shields.io/docs/logos) badges. Light and dark heading variants support both GitHub themes. The README retains accessible image labels and its heading structure.
